# 独立广场接入验证（2026-11-08）

## 行为变化

- 移除人数采集、上报、展示及随机进入的满员筛选，原生软件判断能否加入。
- 使用独立 HTTPS API，CloudBase SDK、项目绑定、迁移和验证工具已移除。
- 列表按首次发布时间排序，续期不提升排名；手动刷新 30 秒，翻页无需等待。
- Python 保管 DPAPI 加密的匿名凭据；页面只提交固定操作，不接触认证凭据。
- 持久化幂等 key、公告代次、待撤下及发布意愿；匿名身份变化后不能沿用旧意愿自动公开。
- 修复空列表在登录状态变化后不更新文案的问题。

## 用户多设备反馈与第二轮修复

用户已确认正常发布/加入、取消发布、撤下、失效房间加入、短暂断网恢复、后台重启恢复和换房/退出登录符合预期。续期排序、多页翻页、长时间断网、浏览者断网及撤下后重启尚待用户实测。

本轮针对反馈修复：

- 房间号与按钮遮挡：三个 Plus 按钮及原生离开按钮改为房间号下方的文档流，窄窗口自动换行。
- 官方断线后撤下按钮消失：将撤下权限与实时房主/连接状态分开，撤销本机意愿后保存待撤下，不能恢复续期。
- 多秒操作延迟：改为 CDP 页面绑定事件、HTTP Future 完成回调和面板状态推送，移除操作搬运轮询；保留原生状态和续期定时器。

实测同一路径健康接口 97–116 ms，自身公告查询约 118 ms。独立 WebView 测试页面经真实 API 再回传页面：刷新约 121 ms，翻页约 112 ms；首次创建测试身份加自身查询约 215 ms。测试期间没有重复调用后台 sync 来推进请求，证明 HTTP 完成和状态交付由事件回调驱动。未以这些数字承诺其他网络环境或所有操作的固定耗时。

原生联机页验证：正常宽度及 420 CSS 像素宽度均不覆盖房间号、按钮不超出容器；模拟官方断线状态时撤下按钮可用，确认窗取消不发送任何命令。预览仅修改和恢复界面，未撤下、公开或离开用户的房间。截图保存在本地 build/plaza-actions-preview.png。

第二轮最终检查：276 项 Python、128 项 JavaScript 测试与语法检查通过；更新后的 EXE 构建、启动 probe、资源、菜单、隔离看门狗及超时退出冒烟检查通过。
